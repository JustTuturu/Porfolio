# Portfolio - Tut

Personal portfolio website for an AI/ML Engineer based in Ho Chi Minh City, Vietnam.

## Tech Stack

- **Framework**: Astro 6.x
- **Styling**: Tailwind CSS 4.x
- **Deployment**: Vercel
- **Package Manager**: pnpm
- **Node.js**: 24.x

## Getting Started

```bash
pnpm install
pnpm dev
```
